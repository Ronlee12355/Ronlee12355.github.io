Databases

Database 2020

ncRNA-eQTL

A pan-cancer atlas of SNP effects on non-coding RNA expression

Genome-wide cis- and trans-ncRNA-eQTLs across 33 TCGA cancer types, linking germline variants to ncRNA expression, patient survival and GWAS risk loci — searchable, browsable and downloadable.

  • 33 cancer types
  • 8,700+ samples
  • 6.8M+ eQTL pairs
First author

Database 2026

PCsRNAdb

Search and analyse small non-coding RNAs across cancers

190 small RNA-seq datasets, 11,114 samples and 19 cancer types covering miRNAs, piRNAs, tDRs, rRFs and more, with four online analysis modules: differential expression, survival, expression profiling and regulatory networks.

  • 19 cancer types
  • 11,114 samples
  • 4 analysis modules

Tools & pipelines

Tool 2024

GCclassifier

Predict gastric cancer subtypes from an expression profile

An R package for gastric cancer molecular subtype prediction, with an interactive web server so that non-bioinformaticians can upload a profile and get a subtype call.

  • R package
  • Web server
  • Validated on independent cohorts
First author
GitHub repositoryPaper DOI
Protocol code 2025

STAR Protocols Code

Reproducible code for tumour prognosis modelling and subtyping

R code and demo data for the STAR Protocols paper: gene-signature modelling, subtype identification, classifier training, subtype-specific network inference and drug-sensitivity analysis, end to end.

  • R code
  • Demo data
  • End-to-end protocol
